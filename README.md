# English Workbook

Тренажёр английского (B1–C1): любая статья превращается в интерактивный рабочий лист в стиле Cambridge / Pearson. Тест составляет ИИ (ChatGPT, Claude, Gemini и т.п.), а сайт отрисовывает его, проверяет ответы и готовит отчёт с ошибками для разбора.

Это статический сайт без сервера и регистрации. Все данные остаются в вашем браузере.

## Как пользоваться
1. Вставьте текст статьи, выберите уровень и при желании грамматические темы. Нажмите «Скопировать промт + текст» и отправьте это ИИ.
2. Вставьте ответ ИИ (JSON) и нажмите «Открыть тест».
3. Решите тест и нажмите «Проверить» (Ctrl+Enter). Ошибки сразу копируются в буфер обмена вместе с инструкцией для ИИ.
4. Вставьте отчёт в чат. ИИ пришлёт разбор ошибок и новый JSON для повторения. Вставьте его в блок «Следующий раунд» внизу страницы. Повторяйте, пока ошибок не останется.

Кнопка «Демо-тест» на главной открывает готовый пример.

## Проверка ответов
- **Регистр.** Ответ с неверной заглавной или строчной буквой засчитывается как отдельная ошибка (`monday` вместо `Monday`, `The` в середине предложения). Если пропуск стоит в начале предложения, заглавная буква обязательна. Строгую проверку можно отключить в ⚙.
- **Без ошибки засчитываются:**
  - сокращённые и полные формы (`don't` = `do not`);
  - лишние пробелы;
  - разные кавычки;
  - точка в конце.
- **Опечатки:** близкие по написанию ответы помечаются как «похоже на опечатку».
- **Переводы и эссе:** если ответ не совпал с ключом, он уходит на проверку ИИ.

## Где хранятся данные
Тесты, попытки и банк ошибок хранятся в `localStorage` браузера. Это значит:
- данные видны только в этом браузере на этом устройстве, на сервер ничего не отправляется;
- если очистить данные сайта или открыть его в приватном режиме, данные пропадут;
- чтобы перенести данные на другое устройство, используйте кнопки **«Резервная копия» / «Восстановить»** на главной.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите в него содержимое этой папки так, чтобы `index.html` лежал в корне.
2. В репозитории откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch**. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
3. Через минуту-две сайт будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Локально сайт тоже работает: достаточно открыть `index.html` двойным кликом.

## Структура
| Файл | Назначение |
|---|---|
| `index.html`, `style.css`, `app.js` | интерфейс и логика проверки |
| `store.js` | хранение в браузере, резервные копии |
| `prompts/*.md` | промты для ИИ: генерация, разбор ошибок, схема JSON |
| `prompts.js`, `demo.js` | собранные из `prompts/` и `examples/` версии для браузера |
| `build_assets.py` | пересборка `prompts.js` и `demo.js` |

Если вы изменили промты в `prompts/*.md`, выполните `python build_assets.py` и закоммитьте обновлённый `prompts.js`.
