# Language Workbook

Тренажёр иностранных языков: любой текст превращается в интерактивный рабочий лист. Тест составляет ИИ (ChatGPT, Claude, Gemini и т.п.), а сайт отрисовывает его, проверяет ответы и готовит отчёт об ошибках для разбора.

| Язык | Уровни | Стиль заданий |
|---|---|---|
| Английский | CEFR A1–C2 | Cambridge, IELTS |
| Немецкий | CEFR A1–C2 | Goethe, telc |
| Французский | CEFR A1–C2 | DELF, DALF |
| Итальянский | CEFR A1–C2 | CELI, CILS |
| Китайский | HSK 3.0, 1–6 | HSK |

Это статический сайт: без сервера и без регистрации. Все данные остаются в вашем браузере.

## Как пользоваться
1. Выберите язык. Вставьте текст статьи, укажите уровень и при желании грамматические темы. Нажмите «Скопировать промт + текст» и отправьте это ИИ.
2. Вставьте ответ ИИ (JSON) и нажмите «Открыть тест». Язык теста определяется автоматически.
3. Решите тест и нажмите «Проверить» (Ctrl+Enter). Ошибки сразу копируются в буфер обмена вместе с инструкцией для ИИ.
4. Вставьте отчёт в чат. ИИ пришлёт разбор и новый JSON для повторения. Вставьте его в блок «Следующий раунд». Повторяйте, пока ошибок не останется.

Если исходный текст сложнее вашего уровня или написан на русском, ИИ адаптирует его под уровень.
У каждого языка есть «Демо-тест» на главной.

## Проверка ответов
Регистр, диакритика и тоны считаются отдельными типами ошибок. Их можно смягчить в ⚙.

**Регистр (все алфавитные языки).** `monday` вместо `Monday`, `haus` вместо `Haus`. Если пропуск стоит в начале предложения, заглавная буква обязательна.

**Диакритика (немецкий, французский, итальянский).** `Muller`, `ecole`, `perche`, `e` вместо `è`. Немецкие замены `ae`, `oe`, `ue`, `ss` распознаются как ошибка диакритики, а не как неверный ответ. Буквы с диакритикой вводятся с панели внизу экрана (ä ö ü ß / é è ç œ / à ì ò ù).

**Китайский:**
- `lǚxíng`, `lv3xing2` и `lu:3 xing2` засчитываются одинаково;
- если буквы верные, а тоны нет, это отдельная ошибка «в тонах»;
- в иероглифах пунктуация и пробелы при проверке не учитываются.

**Без ошибки засчитываются:** лишние пробелы, разные кавычки, точка в конце, английские сокращения (`don't` = `do not`).

**Опечатки:** близкие по написанию ответы помечаются как «похоже на опечатку».

**Переводы и письменные работы:** если ответ не совпал с ключом, он уходит на проверку ИИ.

## Что ещё есть
- **Задания:** вставка слов, выбор ответа, «верно / неверно / нет информации», сопоставление, составление предложения из блоков, исправление ошибки, перевод, письмо.
- **Аудирование и диктант** через синтезатор речи браузера, с медленным режимом. Лучшие голоса — в Microsoft Edge.
- **Словарь:**
  - род существительного выделен цветом;
  - формы слова (мн. ч., основные формы глагола) показываются рядом;
  - перевод можно скрыть для самопроверки;
  - есть экспорт в Anki.
- **Текст:** перевод абзацев для уровней A1–B1, подсветка слов урока, озвучка.
- **Китайский:**
  - пиньинь над иероглифами: скрыт, при наведении или показан (Alt+P);
  - анимация порядка черт и тренировка написания иероглифа мышью.
- **Банк ошибок** по каждому языку: отдельный тест по всем накопленным ошибкам.

## Где хранятся данные
Тесты, попытки и банк ошибок хранятся в `localStorage` браузера.
- Данные видны только в этом браузере на этом устройстве. На сервер ничего не отправляется.
- Если очистить данные сайта или открыть его в приватном режиме, данные пропадут.
- Чтобы перенести данные на другое устройство, используйте кнопки **«Резервная копия» / «Восстановить»**.
- Данные первой (только английской) версии сайта подхватываются автоматически. Старые резервные копии тоже восстанавливаются.

## Публикация на GitHub Pages
1. Загрузите содержимое папки в репозиторий так, чтобы `index.html` лежал в корне.
2. Откройте **Settings → Pages → Deploy from a branch**, выберите ветку `main` и папку `/ (root)`.
3. Сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Локально сайт тоже работает: достаточно открыть `index.html` двойным кликом.

## Структура
| Файл | Назначение |
|---|---|
| `index.html`, `style.css`, `app.js` | интерфейс и проверка ответов |
| `langs.js` | профили языков: уровни, грамматические банки, методические заметки для ИИ, озвучка, спецсимволы |
| `store.js` | хранение в браузере, резервные копии |
| `prompts/alpha/*.md` | промты для английского, немецкого, французского, итальянского (общий шаблон, язык подставляется) |
| `prompts/zh/*.md` | промты для китайского |
| `examples/demo_*.json` | демо-тесты |
| `prompts.js`, `demo.js` | версии для браузера, собранные из `prompts/` и `examples/` |
| `build_assets.py` | пересборка `prompts.js` и `demo.js` |

Если вы изменили промты или демо, выполните `python build_assets.py` и закоммитьте обновлённые `prompts.js` и `demo.js`.

### Как добавить язык
1. Добавьте профиль в `langs.js`: уровни, грамматика, `notes` для ИИ, `tts` (например `es-ES`), `chars`, `hue`.
2. Добавьте код языка в `LANG_ORDER` в том же файле.
3. Добавьте строку в `TF_NATIVE` в `app.js` и строку `:root[data-lang="…"]` с цветом в `style.css`.
