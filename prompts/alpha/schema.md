## ФОРМАТ JSON (схема workbook/v2) — соблюдай строго

### Правила JSON
- Выдай ровно ОДИН JSON-объект в одном блоке ```json ... ```. Без комментариев внутри JSON, без висячих запятых.
- Внутри строк используй обычный апостроф ' (не ’), двойные кавычки внутри строк экранируй: \".
- Пропуск в предложении — ровно три подчёркивания: ___ (один ___ = одно поле ввода). Никаких других подчёркиваний.
- Ответы пиши С ПРАВИЛЬНЫМ РЕГИСТРОМ И ДИАКРИТИКОЙ — ровно так, как слово должно стоять в предложении. Программа отдельно проверяет заглавные буквы и диакритику (ä, ß, é, è, à…). Если пропуск в начале предложения — ответ с заглавной.
- Если допустимо несколько правильных ответов — перечисли ВСЕ разумные варианты в массиве.
- "answer" в multiple_choice и matching — ТОЧНАЯ копия текста правильного варианта (не буква и не номер).
- "explanation" (необязательно, по-русски, 1–2 предложения) показывается после проверки — добавляй к грамматическим заданиям.
- "audio" (необязательно, в пунктах gap_fill / multiple_choice / true_false / open) — текст, который программа ОЗВУЧИТ голосом, но не покажет до проверки. Так делаются аудирование и диктант.

### Корневая структура
```json
{
  "schema": "workbook/v2",
  "language": "{{LANG_CODE}}",
  "meta": {"title": "Короткое название (по-русски)", "level": "B1", "topic": "Тема", "round": 1, "grammar_topics": ["…", "…"]},
  "text": {
    "title": "Заголовок статьи",
    "paragraphs": [{"text": "Абзац 1 … **выделенное слово** …", "ru": "Перевод абзаца (только A1–B1)"}]
  },
  "review": null,
  "vocabulary": [
    {"word": "слово или фраза (существительные — с артиклем, если он есть в языке)", "in_text": "форма, как в тексте", "gender": "m", "plural": "форма мн. ч. / основные формы глагола (необязательно)", "ipa": "транскрипция (необязательно)", "ru": "контекстный перевод", "pos": "сущ.", "example": "Новый пример", "example_ru": "Перевод примера"}
  ],
  "grammar_notes": [
    {"title": "Название темы", "explanation": "Объяснение по-русски: формула, когда употребляется, ловушки.", "examples": ["Пример — перевод"]}
  ],
  "sections": [{"title": "Лексика", "tasks": [ /* задания, см. ниже */ ]}]
}
```
- "vocabulary[].in_text" — форма ровно как в тексте (для подсветки), иначе пустая строка. "gender": "m" / "f" / "n" или пусто.

### Типы заданий
Общие поля: "id" ("A", "G1", "L2"…), "type", "title" (по-русски), "instruction" (по-русски; для B2+ можно на изучаемом языке), "items".

1) gap_fill — поля ввода в пропусках:
```json
{"id": "B", "type": "gap_fill", "title": "Слова в контексте", "instruction": "Вставьте слова из рамки в нужной форме.", "box": ["слово1", "слово2"],
 "items": [
   {"text": "Предложение с ___ пропуском.", "answers": [["ответ", "вариант"]], "explanation": "…"},
   {"text": "Два ___ пропуска в одном ___.", "answers": [["первый"], ["второй"]]},
   {"prompt": "Исходное предложение.", "key": "KEYWORD", "text": "Новое предложение с ___ .", "answers": [["2-5 слов с ключевым словом"]]},
   {"audio": "Текст для диктанта целиком.", "text": "Текст для ___ целиком.", "answers": [["диктанта"]]}
 ]}
```
   "answers": по одному элементу на каждый ___; каждый элемент — массив допустимых вариантов. Для словообразования базовое слово ЗАГЛАВНЫМИ в скобках в конце "text".

2) multiple_choice:
```json
{"id": "H", "type": "multiple_choice", "title": "…", "instruction": "Выберите правильный вариант.",
 "items": [{"question": "Вопрос?", "options": ["вариант 1", "вариант 2", "вариант 3"], "answer": "вариант 2", "explanation": "…"},
           {"audio": "Реплика/диалог для прослушивания.", "question": "Вопрос по услышанному?", "options": ["…", "…", "…"], "answer": "…"}]}
```

3) true_false:
```json
{"id": "I", "type": "true_false", "title": "…", "instruction": "…", "options": ["T", "F", "NG"], "items": [{"statement": "…", "answer": "NG"}]}
```

4) matching — правая колонка перемешивается программой:
```json
{"id": "A", "type": "matching", "title": "…", "instruction": "…", "items": [{"left": "слово", "answer": "определение"}], "extra": ["дистрактор"]}
```

5) word_order — собрать предложение из блоков (программа перемешает их сама):
```json
{"id": "G3", "type": "word_order", "title": "Порядок слов", "instruction": "Составьте предложение.",
 "items": [{"words": ["Gestern", "bin", "ich", "ins Kino", "gegangen"], "answers": ["Gestern bin ich ins Kino gegangen", "Ich bin gestern ins Kino gegangen"], "ru": "Вчера я ходил в кино."}]}
```
   В "words" — без финальной точки, регистр как в правильном предложении. В "answers" — ВСЕ грамматически верные порядки (если первое слово в другом порядке пишется со строчной, программа это учтёт).

6) error_correction — в предложении одна ошибка, ученик переписывает его целиком:
```json
{"id": "G4", "type": "error_correction", "title": "…", "instruction": "Исправьте ошибку.", "items": [{"text": "Предложение с ошибкой.", "answers": ["Исправленное предложение."], "explanation": "…"}]}
```

7) open — перевод, ответ своими словами, «что означают числа». Совпало с "answers" — засчитывается автоматически, иначе уходит на проверку ИИ:
```json
{"id": "E", "type": "open", "title": "Перевод", "instruction": "Переведите.", "items": [{"text": "Русское предложение.", "answers": ["Вариант 1.", "Вариант 2."], "model_answer": "Лучший вариант."}]}
```

8) writing — письменная работа (проверяет ИИ):
```json
{"id": "W", "type": "writing", "title": "Письмо", "instruction": "…", "min_words": 150, "max_words": 190, "required_words": ["…", "…"]}
```

9) discussion — вопросы для говорения (не проверяются):
```json
{"id": "S", "type": "discussion", "title": "Говорение", "instruction": "…", "items": [{"text": "Вопрос?", "ru": "Перевод (A1–B1)"}]}
```

### Блок "review" (только в раундах повторения)
```json
"review": {"summary": "Общий вывод по ошибкам (по-русски).", "items": [{"mistake": "мой вариант", "correct": "правильно", "rule": "Тема", "explanation": "Почему так, коротко."}]}
```
