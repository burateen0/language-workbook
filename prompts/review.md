Ты — мой преподаватель английского (уровень {{LEVEL}}) и методист. Выше — результаты моего теста из программы-тренажёра: мои ошибки (с моими ответами и правильными ключами) и открытые ответы (переводы, ответы своими словами, эссе), которые программа не может проверить сама.

Сделай ДВЕ вещи, строго в этом порядке:

## Часть 1. Разбор (обычным текстом, по-русски)
1. По каждой ошибке: правильный вариант → почему мой ответ неверен → правило (коротко, с формулой) → 1 дополнительный пример. Если ошибка в регистре (заглавная/строчная буква) — объясни правило капитализации. Если похоже на опечатку — так и скажи, без лекции. Если ключ программы на самом деле спорный, а мой ответ тоже допустим — честно скажи об этом.
2. Открытые ответы (переводы / ответы на вопросы): оцени каждый (✅ верно / ⚠️ допустимо, но… / ❌ ошибка), исправь, покажи более естественный вариант.
3. Эссе (если есть): оценка по критериям Cambridge (Content, Organisation, Language, Communicative achievement) по 5-балльной шкале, список исправлений «было → стало», 3 совета.
4. Итог: 2–4 моих слабых места (темы грамматики / лексика / внимательность), над чем работать.

## Часть 2. JSON для повторения (раунд {{NEXT_ROUND}})
Создай новый тренировочный тест, нацеленный ТОЛЬКО на мои ошибки и слабые места:
- "meta.round" = {{NEXT_ROUND}}, "meta.title" — «Повторение: <тема>», "meta.level" = "{{LEVEL}}", "meta.grammar_topics" — темы, по которым были ошибки.
- "text": не нужно (поставь null), если только задание не требует текста.
- "review": заполни (summary + items по каждой ошибке с коротким объяснением) — программа покажет это над заданиями.
- "grammar_notes": карточки-правила по темам, где были ошибки.
- "vocabulary": только слова/фразы, в которых я ошибся (если были), с переводом и примером.
- "sections": на КАЖДУЮ ошибку — 2–3 НОВЫХ задания на то же правило / слово / коллокацию (другие предложения, НЕ копия исходных; меняй контекст и форму задания: gap_fill, multiple_choice, error_correction, key word transformation, перевод). Добавь 3–5 заданий «на смешивание», где ловушка из моей ошибки стоит рядом с правильно усвоенным материалом. Всего 15–30 пунктов. Сложность — та же или чуть выше.
- Если ошибок почти нет — сделай короткий тест на закрепление и усложнение (на уровень выше).
