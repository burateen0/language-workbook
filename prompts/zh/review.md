## Часть 1. Разбор (обычным текстом, по-русски; китайские слова — с пиньинем в скобках)
1. По каждой ошибке: правильный вариант → почему мой ответ неверен → правило (коротко, с формулой) → 1 дополнительный пример с переводом.
   - Ошибка в тонах: покажи правильные тоны, дай мнемонику или пары-сравнения (например mǎi «покупать» vs mài «продавать»).
   - Неверный иероглиф: если это похожий иероглиф или омофон — покажи разницу (ключ, значение) и как не путать.
   - Порядок слов: покажи схему предложения (Подлежащее + Время + Место + Глагол + …).
   - Если ключ программы спорный, а мой ответ тоже допустим — честно скажи.
2. Открытые ответы (переводы): оцени каждый (✅ / ⚠️ допустимо, но… / ❌), исправь, покажи более естественный вариант с пиньинем.
3. Сочинение (если есть): оценка по критериям HSK-письма (содержание, грамматика, лексика, связность) по 5-балльной шкале, исправления «было → стало», 3 совета.
4. Итог: 2–4 моих слабых места (тоны / иероглифы / грамматика / порядок слов / лексика), над чем работать.

## Часть 2. JSON для повторения (раунд {{NEXT_ROUND}})
Создай новый тренировочный тест, нацеленный ТОЛЬКО на мои ошибки и слабые места:
- "language" = "zh", "meta.round" = {{NEXT_ROUND}}, "meta.title" — «Повторение: <тема>», "meta.level" = "{{LEVEL}}", "meta.grammar_topics" — темы, где были ошибки.
- "text": null (если задание не требует текста).
- "review": заполни (summary + items по каждой ошибке с коротким объяснением) — программа покажет это над заданиями.
- "grammar_notes": карточки-правила по темам с ошибками.
- "vocabulary": слова, в которых я ошибся (иероглиф, тоны, значение), с примером.
- "sections": на КАЖДУЮ ошибку — 2–3 НОВЫХ задания на то же правило/слово (другие предложения; меняй форму: gap_fill, multiple_choice, word_order, pinyin, error_correction, перевод, аудирование с "audio"). Ошибки в тонах → pinyin-задание с этими и похожими словами. Ошибки в иероглифах → gap_fill/multiple_choice с похожими иероглифами в дистракторах. Добавь 3–5 смешанных заданий. Всего 15–30 пунктов, уровень тот же или чуть выше.
- Если ошибок почти нет — короткий тест на закрепление и усложнение.
