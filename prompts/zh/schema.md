## ФОРМАТ JSON (схема chinesetest/v1) — соблюдай строго

### Разметка пиньиня (ОБЯЗАТЕЛЬНО)
Весь китайский текст, который читает ученик (абзацы, вопросы, варианты ответов, утверждения, примеры, слова в "box", "words", "left"/"answer" в matching, вопросы для обсуждения), размечай ПО СЛОВАМ так: `{汉字|hànzì}`.
- Пиньинь — с диакритикой тонов (ā á ǎ à, ü), строчными (кроме имён собственных), БЕЗ учёта тонового сандхи (不 = bù, 一 = yī, 你好 = nǐ hǎo).
- Делить по словам, а не по иероглифам: `{我|wǒ}{昨天|zuótiān}{去|qù}{了|le}{图书馆|túshūguǎn}。`
- Пунктуацию и пропуски ___ оставляй ВНЕ фигурных скобок.
- НЕ размечай: "answers" (ответы — только чистые иероглифы), "text" в заданиях типа pinyin (иначе ученик увидит ответ), "audio".

### Правила JSON
- Выдай ровно ОДИН JSON-объект в одном блоке ```json ... ```. Без комментариев, без висячих запятых. Двойные кавычки внутри строк экранируй: \".
- Только упрощённые иероглифы.
- Пропуск в предложении — ровно три подчёркивания: ___ (один ___ = одно поле ввода).
- "answers" — массив ВСЕХ допустимых вариантов (например ["已经", "早就"]). Пунктуация и пробелы при проверке игнорируются.
- "answer" в multiple_choice — точная копия правильного варианта из "options" (разметка пиньиня допустима, при сравнении она игнорируется).
- "explanation" (необязательно, по-русски, 1–2 предложения) — показывается после проверки; добавляй к грамматическим заданиям.
- "audio" (необязательно, в любом пункте gap_fill / multiple_choice / true_false / open) — чистый китайский текст без разметки, который программа ОЗВУЧИТ, а показывать не будет до проверки. Так делаются аудирование и диктант.

### Корневая структура
```json
{
  "schema": "chinesetest/v1",
  "language": "zh",
  "meta": {"title": "Название по-русски", "level": "HSK3", "topic": "Тема", "round": 1, "grammar_topics": ["把字句", "Дополнение результата"]},
  "text": {
    "title": "{北京|Běijīng}{的|de}{胡同|hútòng}",
    "title_ru": "Пекинские хутуны",
    "paragraphs": [{"zh": "{胡同|hútòng}{是|shì}{北京|Běijīng}{的|de}…", "ru": "Хутуны — это … (перевод абзаца)"}]
  },
  "review": null,
  "vocabulary": [
    {"zh": "胡同", "py": "hútòng", "ru": "переулок (в старом Пекине)", "hsk": 4, "pos": "сущ.", "example": "{我|wǒ}{家|jiā}{在|zài}{胡同|hútòng}{里|lǐ}。", "example_ru": "Мой дом в хутуне."}
  ],
  "grammar_notes": [
    {"title": "把字句", "explanation": "По-русски: формула, когда употребляется, типичные ошибки русскоговорящих.", "examples": ["{我|wǒ}{把|bǎ}{书|shū}{放|fàng}{在|zài}{桌子|zhuōzi}{上|shang}。 — Я положил книгу на стол."]}
  ],
  "sections": [{"title": "词汇 · Лексика", "tasks": [ /* задания */ ]}]
}
```
"vocabulary[].zh/py" — без фигурных скобок. В "text.paragraphs" ключевые слова для задания «слова в тексте» можно выделить **жирным**: `**{胡同|hútòng}**`.

### Типы заданий
Общие поля: "id" ("A", "G1", "L2"…), "type", "title" (по-русски), "instruction" (по-русски), "instruction_zh" (необязательно, как в HSK: "选词填空"), "items".

1) gap_fill — вписать иероглифы:
```json
{"id": "C", "type": "gap_fill", "title": "Слова в контексте", "instruction": "Вставьте слова из рамки.", "instruction_zh": "选词填空",
 "box": ["{已经|yǐjīng}", "{终于|zhōngyú}", "{打算|dǎsuan}"],
 "items": [
   {"text": "{我|wǒ}___{吃|chī}{饭|fàn}{了|le}。", "answers": [["已经"]]},
   {"text": "{他|tā}{把|bǎ}{作业|zuòyè}{写|xiě}___{了|le}。", "answers": [["完", "好"]], "explanation": "Дополнение результата: 写完 — дописал."},
   {"audio": "我明天打算去上海。", "text": "{我|wǒ}{明天|míngtiān}___{去|qù}{上海|Shànghǎi}。", "answers": [["打算"]]}
 ]}
```
   "answers": по одному элементу на каждый ___; каждый элемент — массив допустимых вариантов.

2) pinyin — написать пиньинь к иероглифам (с тонами):
```json
{"id": "B", "type": "pinyin", "title": "Пиньинь и тоны", "instruction": "Напишите пиньинь с тонами.",
 "items": [{"text": "旅行", "ru": "путешествовать", "answers": ["lǚxíng"]}]}
```

3) multiple_choice:
```json
{"id": "H", "type": "multiple_choice", "title": "…", "instruction": "Выберите правильный вариант.",
 "items": [{"question": "{他|tā}{为什么|wèishénme}…？", "options": ["{因为|yīnwèi}…", "…", "…"], "answer": "{因为|yīnwèi}…", "explanation": "…"},
           {"audio": "男：你周末去哪儿了？女：我去爬山了。", "question": "{女|nǚ}{的|de}{周末|zhōumò}{做|zuò}{什么|shénme}{了|le}？", "options": ["{爬山|páshān}", "{游泳|yóuyǒng}", "{看|kàn}{电影|diànyǐng}"], "answer": "{爬山|páshān}"}]}
```

4) true_false — 对 / 错 (и при желании «нет информации»):
```json
{"id": "I", "type": "true_false", "title": "…", "instruction": "Верно или неверно?", "instruction_zh": "判断对错", "options": ["T", "F"],
 "items": [{"statement": "{胡同|hútòng}{很|hěn}{新|xīn}。", "answer": "F"}]}
```
   "options": ["T","F"] или ["T","F","NG"].

5) matching — сопоставление (слово ↔ перевод, реплика ↔ ответ, абзац ↔ заголовок). Правая колонка перемешивается автоматически:
```json
{"id": "A", "type": "matching", "title": "…", "instruction": "Сопоставьте слова и переводы.",
 "items": [{"left": "{胡同|hútòng}", "answer": "переулок"}], "extra": ["лишний вариант (необязательно)"]}
```

6) word_order — составить предложение из слов (连词成句). Слова программа перемешает сама:
```json
{"id": "G3", "type": "word_order", "title": "Порядок слов", "instruction": "Составьте предложение.", "instruction_zh": "连词成句",
 "items": [{"words": ["{我|wǒ}", "{昨天|zuótiān}", "{去|qù}{了|le}", "{图书馆|túshūguǎn}"], "answers": ["我昨天去了图书馆", "昨天我去了图书馆"], "ru": "Я вчера ходил в библиотеку.", "explanation": "Время стоит перед глаголом."}]}
```
   В "words" — без финальной точки. В "answers" — ВСЕ грамматически верные порядки.

7) error_correction — 病句: в предложении одна ошибка, ученик переписывает его целиком:
```json
{"id": "G4", "type": "error_correction", "title": "…", "instruction": "Исправьте ошибку.",
 "items": [{"text": "{我|wǒ}{去|qù}{了|le}{北京|Běijīng}{两|liǎng}{次|cì}{过|guo}。", "answers": ["我去过两次北京。", "我去过北京两次。"], "explanation": "…"}]}
```

8) open — перевод с русского на китайский, ответ на вопрос. Если совпало с "answers" — засчитывается автоматически, иначе уходит на проверку ИИ:
```json
{"id": "E", "type": "open", "title": "Перевод", "instruction": "Переведите на китайский.",
 "items": [{"text": "Я уже прочитал эту книгу.", "answers": ["我已经看完这本书了", "这本书我已经看完了"], "model_answer": "{我|wǒ}{已经|yǐjīng}{看完|kànwán}{这|zhè}{本|běn}{书|shū}{了|le}。"}]}
```

9) writing — сочинение (проверяет ИИ):
```json
{"id": "W", "type": "writing", "title": "写作 · Письмо", "instruction": "Напишите текст о …, используя слова ниже.", "min_chars": 80, "max_chars": 120, "required_words": ["胡同", "已经", "打算"]}
```

10) discussion — вопросы для устной практики (не проверяются):
```json
{"id": "S", "type": "discussion", "title": "口语 · Говорение", "instruction": "Ответьте устно.", "items": [{"text": "{你|nǐ}{喜欢|xǐhuan}…？", "ru": "Вам нравится…?"}]}
```

### Блок "review" (только в раундах повторения)
```json
"review": {"summary": "Общий вывод по-русски.", "items": [{"mistake": "我去了北京两次过", "correct": "我去过北京两次", "rule": "过 и счётные глаголов", "explanation": "Коротко по-русски."}]}
```
